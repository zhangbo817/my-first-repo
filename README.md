# my-first-repo

This is my first GitHub repository — a place to practice Git and keep my code.

## 编译与运行（C 语言版）

本仓库的 C 项目在 `game/` 目录，源码是单文件 `game/game.c`（**纯 C，C11 标准**），
只用标准库，不需要任何第三方依赖，有 C 编译器就能跑。

**Windows（MinGW / Dev-C++ 的 gcc）**

```bat
cd game
build.bat
:: 或者直接手敲
gcc -std=c11 -O2 -o game.exe game.c
game.exe
```

**Linux / macOS**

```bash
cd game
gcc -std=c11 -O2 -o game game.c
./game
```

无人值守自检（跑 30000 帧后打印统计，用来确认编译产物是可运行的）：

```bash
game.exe --selftest 30000
```

操作：`W/A/S/D` 移动 · `J`/`L` 转向瞄准 · `空格` 开关持续开火 · `C` 冲刺闪避 · `Tab` 商店/装备/机库面板 · `X` 退出。

> 也可以用 VS Code / Visual Studio 打开 `game/game.c` 直接 F5 编译运行；`build.bat` 会自动依次尝试 MSVC → gcc → Dev-C++ MinGW。

#### 手机也能玩（触屏版）

`game.html` 会自动识别触屏设备，手机/平板打开同一个链接就会切换成手游操作，PC 端仍然是键鼠，两边共用一份文件：

| 位置 | 作用 |
| --- | --- |
| 左下角 | 虚拟摇杆：手指按在左半屏任意位置即出现摇杆，拖动移动（带 0~1 模拟量，轻推慢走） |
| 右下角 | 攻击键（按住持续开火）+ 冲刺键（闪避无敌） |
| 左上角 | 商店（补给站 / 战机 / 宠物 / 强化 / 机库 / 图纸） |
| 右上角 | 暂停 |
| 瞄准 | 没有鼠标，改为自动锁定最近的敌人；范围内没有敌人时朝摇杆方向 |

**手机端全程横屏**（只影响触屏设备，电脑端仍是可缩放窗口 + 键鼠）：

- 竖屏打开先盖一层「点一下进入横屏」，点屏幕任意位置 → 自动进全屏并锁定横屏方向，之后就一直是横屏。
- 浏览器不支持锁方向（如 iOS Safari）或者系统锁了竖屏方向时，会自动把**整个游戏画面旋转 90°**兜底，
  视觉上依然是横屏——把手机横过来就能玩，不需要去改系统设置。
- 战斗中如果手机变回竖屏，游戏会自动暂停，转回横屏再点「继续」。

调试时可用 `?touch=1` 强制开启触屏 UI、`?touch=0` 强制关闭。

#### 阶段专属精英小怪

每个阶段（5 关）都有自己的精英小怪，机制与同阶段 BOSS 同源，
在**每个阶段的 4 个普通关**里各出现 1 只（BOSS 关不出）。

它们不是"缩小版 BOSS"，而是**独立的幼体形态**；血量降到 50% 以下会**变态**成第二形态
（外形重画、速度 ×1.25、技能翻倍）：

| 阶段 | 关卡 | 精英 | 幼体形态 | 变态后 |
| --- | --- | --- | --- | --- |
| 1 | 1–4 | 晶簇幼体 | 带背刺的矿物小蟹 | 外壳炸开成六刺晶球，3 发 → 5 发弹幕 |
| 2 | 6–9 | 棱光浮游 | 水母状伞盖 + 触须 | 伞盖张成四瓣棱镜，激光 1 束 → 2 束 |
| 3 | 11–14 | 熔渣爬行者 | 贴地的熔岩虫 | 站起来成四足熔岩兽，陨石 1 颗 → 2 颗 |
| 4 | 16–19 | 裂空掠袭者 | 振翅的飞虫 | 双翅合成刀翼，冲刺更快更远 |
| 5 | 21–24 | 虫巢孵育体 | 背卵囊的甲虫 | 卵囊爆开、触须外翻，孵化 1 只 → 2 只 |
| 6 | 26–29 | 虚空残影 | 幽魂水滴 | 坍缩成小型黑洞，十字弹 → 六向弹 |

精英不会被"撞一下同归于尽"，撞到你会把你顶开；击杀时有专门提示。

#### 补给站与强化（网页版）

- 原来固定在右侧的面板改成**右上角「补给站」弹窗**：`Tab` 开关，数字键 `1~4` 切页，
  商店 / 强化 / 机库 / 图纸全在里面，弹窗打开时游戏自动暂停。
- **每关通关后弹出三选一强化**（海克斯式，效果永久叠加，同一项可叠多层）：

| 稀有度 | 示例强化 |
| --- | --- |
| 白银（常见） | 动能增强 +15% 伤害 · 冷却回路 -8% 间隔 · 附加装甲 +25 生命 · 磁力场 |
| 黄金（稀有） | 过载核心 +30% 伤害但 -10% 生命 · 裂解瞄准 +12% 暴击 · 致命打击 +50% 暴伤 · 穿甲弹芯 贯穿+1 |
| 棱彩（传说） | 多管齐射 每枪 +1 子弹 · 崩解弹 击杀爆炸 · 冲击波 冲刺震伤 · 全弹暴击 · 超载协议 |

最终 BOSS 前还会再给一次强化机会。

#### 战机（商店购买 + 升级 + 武器挂载）

「战机」页把机体做成分级商品，越贵武器越强：

| 阶级 | 机型 | 价格 | 能量 / 挂点 | 自带武器 |
| --- | --- | --- | --- | --- |
| T1 | 夜隼 / 龙吟 / 混天 | 初始自带 | 4 / 1 | 单管机炮 / 三管阵列 / 单管机炮 |
| T2 | 蜂群 | 220 | 6 / 1 | 三管阵列 |
| T2 | 棱镜 | 280 | 6 / 1 | 聚焦激光 |
| T3 | 猎隼 | 480 | 8 / 2 | 五管齐射 |
| T3 | 熔火 | 580 | 8 / 2 | 重炮 |
| T4 | 终焉 | 960 | 11 / 2 | 聚焦激光 |

**武器是独立模块**（参考《创世战车》《战争雷霆》的能量/挂点设计）：
机体阶级决定**能量上限**和**挂点数**，每个武器模块消耗能量，
装不下就只能换更贵的机体。武器模块只需解锁一次，之后可自由换装：

| 模块 | 能量 | 价格 | 效果 |
| --- | --- | --- | --- |
| 单管机炮 | 1 | 自带 | 标准单发 |
| 三管阵列 | 2 | 140 | 3 发散射 |
| 聚焦激光 | 3 | 260 | 穿透光柱 |
| 五管齐射 | 3 | 300 | 5 发宽扇形 |
| 重炮 | 4 | 420 | 单发巨伤 · 贯穿 2 |

- 机体买到即出战，可**升级**：上限 5 级，每级 +10% 伤害、-4% 间隔；费用 = `90 × 阶级 × 当前等级`
- T3 / T4 机体有 2 个挂点，两件武器**同时开火**（各自独立射速）
- 图纸页自组的飞机按「武器槽」给默认模块：G1 单管 / G2 三管 / G3 激光 / G4 五管
- 激光是真实光柱（从机头拉到弹头），并做了线段碰撞，高速下不会穿过小怪

#### 宠物（参考天天酷跑的宠物系统）

「宠物」页有 6 只跟随出战机飞行的小宠物，一只出战、可升级（每级 +15% 效果）：

| 宠物 | 类型 | 价格 | 效果 |
| --- | --- | --- | --- |
| ✈ 护航机 | 攻击 | 180 | 跟随开火，自动打最近的敌人 |
| 🦖 奶妈龙 | 回复 | 160 | 定期回复生命值 |
| 🐉 火焰龙 | 攻击 | 320 | 喷吐三连火球 |
| 🐦 拾荒鸟 | 金币 | 200 | 定期叼回金币 + 磁吸加成 |
| 🛸 护盾碟 | 护盾 | 280 | 受到伤害 -18% |
| ✨ 增幅灵 | 增幅 | 340 | 伤害 +12%，射速 +8% |

升级费用 = `50 × 当前等级`。宠物的攻击/回复/产金各自有独立冷却，被动类（护盾/增幅/磁吸）直接进属性计算。

想看全部外形：打开 `game/game.html?gallery=1`（BOSS + 精英图鉴，见 `bosses.png`）、
`?gallery=2`（精英两种形态对照，见 `elites.png`）。

编译：双击 `build.bat`，或用 MinGW 执行 `gcc game.c -o game.exe`。
